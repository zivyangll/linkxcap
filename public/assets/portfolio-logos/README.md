# Portfolio logo replacements

This directory is the single replacement point for the portfolio grid and
company detail pages. Each filename matches the company's URL slug.

- Keep the existing filename and `.webp` format when replacing a logo.
- Export with a transparent background and retain the logo's official colour.
- Keep comfortable transparent padding around the mark; the page applies the
  grayscale default state and restores the original colour on hover/focus.
- Check the result at 1920px, 1440px and 390px after replacement.

The current files are temporary exports from the reviewed Figma frame. The
design team can replace them one by one without changing code.
