## 限速实验室测量

设备环境：Apple M5 / 16 GB 内存 / macOS 26.4.1。Chromium 无头浏览器，390 × 844 CSS px，DPR 2，触摸模式。每次新建上下文、禁用缓存；CDP 设置下载 1.6 Mbps、上传 750 Kbps、延迟 150 ms、CPU 4 倍减速。本地静态预览服务器。每项三次，保留全部原始值。

| 页面         | LCP 三次，秒          |  中位数 | CLS 三次  | 菜单操作观察到的最大事件耗时 |
| ------------ | --------------------- | ------: | --------- | ---------------------------- |
| 中文首页     | 0.700 / 0.580 / 0.564 | 0.580 s | 0 / 0 / 0 | 56 / 40 / 40 ms              |
| 英文首页     | 0.528 / 0.532 / 0.540 | 0.532 s | 0 / 0 / 0 | 48 / 48 / 48 ms              |
| 中文投资组合 | 1.568 / 1.404 / 1.576 | 1.568 s | 0 / 0 / 0 | 56 / 48 / 48 ms              |

- 以上是实验室实测，不是 Lighthouse 分数，也不是 GitHub Pages 全球网络实测。
- 菜单事件耗时通过 Event Timing 观察，只验证本次脚本操作；**不等于真实用户 INP**。
- 首次版本中文投资组合 LCP 约 3.5 秒。按页面实际用字拆分字体后，上述相同条件三次均低于 2.5 秒；未降低设计字体要求。
- 未接入第三方统计／RUM。正式域名发布后才能依据足量真实访问评估 p75 LCP ≤ 2.5 s、INP ≤ 200 ms、CLS ≤ 0.1。
- 真机 iPhone／Android 的长时间运行、耗电、低内存、以及中国大陆不同运营商网络仍需上线后补充；浏览器模拟不能替代真机结果。

原始数据与条件：[performance-lab.json](verification/performance-lab.json)。复现脚本：`scripts/performance-check.mjs`。
