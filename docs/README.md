## 推荐结论

**Astro 静态生成 + TypeScript + CSS/SVG + GSAP/ScrollTrigger + 按可见区域加载的 Three.js**。会议明确要求真实三维交互，因此首页末屏使用可选 WebGL，投资组合列表保留静态网格和鼠标圆形箭头；正文、导航和链接不依赖三维模块。

## 使用说明

- 文档中的性能数字是开发预算和验收目标，不是现有网站或尚未开发的新网站的实测成绩。
- “已有”表示本轮可读取或可导出，不等于公司已经确认最新版本或授权范围。
- Figma 的 28 个桌面画板包含同一页面的多个状态，不能计作 28 个独立网页。
- `research/` 保存本轮 Figma 读取摘要和证据截图；截图中的文字、数字及企业名称不直接作为发布定稿。
- 按最新要求，素材与待确认项全部使用 Markdown 表格，供直接填写或复制到协作文档。
