## 3. 动效与性能实现

主栈仍为 **Astro 静态生成 + TypeScript + CSS/SVG + GSAP/ScrollTrigger**。本轮为会议明确要求的 3D 场景增加 **Three.js 0.186.0**，通过单独的 `topology` 动态模块加载。

| 项目 | 规则／预算 | 本轮结果 |
| --- | --- | --- |
| 普通 JS 总和（排除可选三维模块） | 保持 ≤120 KiB gzip | 约 50.4 KiB |
| 可选 Three.js＋星图模块 | 单独 ≤145 KiB gzip | 约 129.0 KiB |
| 全部 JS | 本次引入真实三维后 ≤200 KiB gzip | 约 179.4 KiB；不是每页首屏全部加载 |
| 全部 CSS | ≤35 KiB gzip | 约 17.3 KiB |
| 三维加载 | 距视口 120px 才加载；正文、链接不依赖它 | 首页首屏不请求 topology 模块，已通过测试 |
| 降级 | reduced motion、Save Data、可识别低内存设备、模块加载失败、WebGL 创建失败 | 使用服务端生成的静态节点和真实链接 |
| 渲染 | 桌面 DPR ≤1.5，手机 ≤1；总绘制像素 ≤250 万 | 最多 400／130 个背景点；无阴影、后处理或大型纹理 |
| 停止绘制 | 视口外、后台标签、用户暂停、减少动态效果 | 使用 IntersectionObserver、visibilitychange 和媒体查询 |
| 文字和素材 | 字体本地分片；Figma 资源下载到仓库；图片使用已优化素材 | 没有临时 Figma URL 或第三方字体加载依赖；字体 URL 按子集清单版本更新，避免旧缓存与新映射混用 |
| 未验证范围 | 真机持续帧率、耗电、低端安卓长期滚动、生产 RUM | 不用模拟器结果代替真实设备结论 |

构建预算见 `scripts/verify-build.mjs`，参考 [Three.js 文档](https://threejs.org/docs/)和 [GSAP ScrollTrigger 文档](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)。此前 Canvas 方案针对静态背景，本轮因明确的三维要求调整为可选 WebGL；没有引入 React 或服务端运行时。

### 实验室测量

条件：本机 Chromium，390×844、DPR 2、触摸模拟，下载 1.6 Mbps／上传 750 Kbps／150ms 延迟，CPU 4 倍减速，每个页面独立上下文且禁用缓存，三次冷启动。来源为本地静态预览，不包括 GitHub Pages 的实际跨地域传输。

| 页面 | LCP 中位数 | CLS（三次最大值） | 测量窗口资源体积 | 菜单交互最大 Event Timing |
| --- | --- | --- | --- | --- |
| 中文首页 | 600ms | 0 | 435.0 KiB | 64ms |
| 英文首页 | 560ms | 0 | 260.4 KiB | 48ms |
| 中文 Portfolio | 568ms | 0 | 597.5 KiB | 56ms |

- 资源体积取浏览器 Resource Timing 的 encodedBodySize；本地预览服务器不等同于 CDN 压缩后的实际网络传输量。JavaScript／CSS gzip 体积另见构建表。
- 这些是实验室读数，**不是线上 Core Web Vitals 75 分位、也不是 INP**。菜单 Event Timing 仅覆盖脚本执行的打开／关闭操作。
- Portfolio 一次冷启动记录到 144ms 长任务，其余两次未记录长任务；三维冷启动仍是后续真机验证重点。
- 原始记录：[性能 JSON](verification/meeting-revision/performance-report.json)、[构建 JSON](verification/meeting-revision/build-report.json)。微调轨迹和页面边距后的构建体积以 JSON 为准，性能测量对应相同字体及三维模块版本。

## 4. 验证与复现

- 58 项 Chromium／WebKit 浏览器用例全部通过，包括新增的移动端正文边界和 WebGL 创建失败检查。
- 覆盖中文／英文，360、768、1440、1920px 常规页面布局；验证无横向溢出、图片可用、唯一 h1、语言切换、文章过滤、原文链接和无 JS 导航。
- 正常动画模式验证轨迹坐标改变、文字透明度改变、第二屏退出、视频容器变大，避免只测 reduced motion。
- 另检查 38 个中英文公司详情的直接 URL，初始公司不被滚动初始化覆盖。
- 输出 28 张真实浏览器截图，包括首页五章、Portfolio、两家公司详情、团队悬停、Fellow 多状态、洞察，以及主要页面双语手机截图。
- 没有重新宣称逐像素差异归零。原 06 报告是历史静态版本基线，不能作为本轮动态版本的一致性结论。
