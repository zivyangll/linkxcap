# 内容素材文件交付与替换

日期：2026-09-23。

## 1. 对接人只需要替换的两项内容

```text
public/assets/
src/data/content.json
```

`content.json` 中不再保存图片 CDN 地址。所有业务图片字段只填写文件名，网站会按照当前部署的 base path 自动读取：

```text
public/assets/<文件名>
```

例如：

```json
{
  "image_file": "team-alex.webp",
  "logo_file": "zhipu-ai.webp"
}
```

页面实际部署在 `/linkxcap/` 时会自动生成 `/linkxcap/assets/team-alex.webp` 和 `/linkxcap/assets/zhipu-ai.webp`，不需要在 JSON 中填写域名或 base path。

## 2. JSON 图片字段

| 配置位置       | 字段            | 用途              | 当前示例         |
| -------------- | --------------- | ----------------- | ---------------- |
| `site`         | `og_image_file` | 社交分享图        | `og.jpg`         |
| `team[]`       | `image_file`    | 团队成员照片      | `team-alex.webp` |
| `companies[]`  | `logo_file`     | 投资组合公司 Logo | `zhipu-ai.webp`  |
| `media.fellow` | `poster_file`   | Fellow 视频封面   | 空，待提供       |

文件名不得包含目录、`..`、查询参数或 URL。支持 `.avif`、`.gif`、`.jpg`、`.jpeg`、`.png`、`.svg`、`.webp` 图片。

公司官网、社交账号、原文链接和视频播放地址仍然是外部链接，不属于图片 CDN 地址，继续使用完整的 HTTP/HTTPS URL。

## 3. `public/assets` 目录说明

业务人员维护的图片直接放在根目录：

```text
public/assets/og.jpg
public/assets/team-alex.webp
public/assets/zhipu-ai.webp
```

`public/assets/figma/` 保存页面线框、轨道、装饰图和其他设计稿导出资源。交付完整素材目录时必须一起保留，否则页面视觉会缺失。

替换规则：

1. 图片内容变化但文件名不变时，覆盖 `public/assets` 中的同名文件即可。
2. 文件名变化时，同时修改 `content.json` 的对应 `*_file` 字段。
3. 替换后执行 `npm run build`。构建会检查 JSON 引用的图片是否存在。
4. 将新的构建产物部署到静态服务器。

## 4. `src/data` 文件用途核对

| 文件                 | 是否保留 | 实际用途                                         |
| -------------------- | -------- | ------------------------------------------------ |
| `content.json`       | 保留     | 唯一可编辑的全站业务配置                         |
| `assets.json`        | 保留     | 运行时使用的 Figma 节点与本地导出资源映射        |
| `figma-assets.json`  | 保留     | 下载和重新优化 Figma 原始资源时使用的源映射      |
| `fonts.json`         | 保留     | 页面运行时生成本地字体声明和缓存版本             |
| `font-priority.json` | 保留     | 字体子集生成脚本使用的字符优先级数据             |
| `logo-geometry.json` | 保留     | 投资组合拓扑图中的 Logo 几何位置和尺寸           |
| `asset-sizes.json`   | 删除     | 没有运行时或构建读取方，仅是旧优化脚本的输出报告 |

除 `content.json` 外，其余保留文件属于代码和构建数据，不需要公司对接人日常修改。

## 5. 构建校验

以下情况会阻止导出或构建，并指出具体配置路径：

- 图片字段填写了完整 URL；
- 文件名包含目录、`..`、查询参数或不支持的扩展名；
- 必填的团队照片、公司 Logo 或社交分享图为空；
- JSON 引用的文件在 `public/assets` 中不存在。

配置编辑器仍然只编辑和导出 `content.json`，不会上传图片。图片需单独放入 `public/assets`。
