日期：2026-09-23。本次以用户提供的五张参考截图及悬停／自动变化要求为准，修改首页末屏 Focus Areas。随后按最新两张截图补充“关于我们”停靠位置与 H5 动效，详见文末补充。投资组合首页不变。

## 交互规则

| 状态 | 表现 |
| --- | --- |
| 默认展示 | 深灰底、五个紫色菱形分类节点、中央连接点、较暗的主干线。当前分类变为白色菱形，分类名与公司分支呈淡紫色 |
| 无人悬停 | Three.js 围绕星图中心缓慢往复旋转，每约 5.2 秒轮换一个分类；同步更新左侧中英文介绍 |
| 悬停分类节点／标签 | 无需点击，立即选择该分类，停止旋转和轮换，约 620ms 内伸展对应公司分支；节点的位置固定，方便继续查看 |
| 悬停公司链接 | 保持当前分类和星图位置；点击后进入该公司的当前语言详情页 |
| 鼠标移开 | 留出 650ms，允许从节点移动到分支链接；随后恢复旋转，重新计算轮换时间 |
| 拖动空白区域 | 围绕星图中心调整三维视角，松开后继续自动变化；不捕获页面纵向滚动 |
| 键盘 | Tab 聚焦分类或公司时暂停轮换；分类按钮支持 Enter／Space；链接有可见焦点 |
| 手机／平板触屏 | 使用 Three.js 自动轮换、旋转和连接对应公司；点击节点选择并暂停，再次点击当前节点恢复；点击其他节点切换后继续保持暂停。纵向滑动仍用于浏览页面 |
| 减少动态／低配置／模块失败 | 保留 HTML 节点、文案、可点击公司链接；PC／H5 均使用各自布局的 SVG 静态连线 |
| WebGL 上下文丢失 | 恢复静态位置与 SVG 连线；上下文恢复后重新启用三维场景 |
| 页面后台／模块离开视口 | 停止动画帧与轮换计时，重新可见后继续，不补跑后台累积的动画 |

图形的细线、节点深度和姿态由代码生成，无新增图片、视频或运行时依赖。取消该模块之前的密集背景星点和节点方框，采用参考图的稀疏星图。

## 公司与分类数据

- 唯一业务来源仍是 `src/data/content.json`：分类名／介绍读取 `sectors`，公司名／详情链接读取 `companies`。
- 根据 `companies[].sector_id` 自动生成对应分支。新增、删除、修改公司后，重新构建即可同步星图，不再单独维护三套硬编码公司名单。
- 当前数据：智能基础层 4 家、AI 基础设施 8 家、智能体与 AI 原生应用 4 家、物理智能 3 家、长期前沿 0 家。
- 长期前沿仍能被悬停、选择、自动轮换，显示分类介绍与主干连接；没有公司配置时不虚构公司分支。
- 年份沿用现有 `pages.home.focus.investment_year` 配置的共享年份，不从截图识别内容推断或新增公司投资事实。
- `src/lib/focus-layout.ts` 仅保存坐标、深度、文字方向及新增记录的布局规则，不保存公司事实或文案。

## 本轮补充：About Us 停靠与 H5 动效

- **PC 弧线过渡**：保留首段停在 AGI 章节；随后“远星初亮”走过实际弧线距离的三分之一时，自动推进到 About Us 节点刚出现的中间状态（哲学章节进度约 58%）。此时标题保持渐进模糊，继续下滑才展开完整正文。其他章节沿用剩余约四分之一时吸附的行为。
- **H5 首屏**：无需滚动，标题在约 1.3 秒内从轮廓／虚化状态变成实字，正文与章节标记同时自动渐显。弧线、节点及后续文字随触屏滚动推进，独立于 PC 时间线。
- **H5 星图**：与 PC 共用分类和公司关联；针对窄屏重排坐标与标签，保留主干线、公司分支伸展及轻微三维旋转。约 5.2 秒自动切换分类，点击暂停／再次点击当前节点恢复。
- **渲染预算**：H5 最高约 25fps、DPR 1.25、90 万像素；PC 保留约 30fps、DPR 1.5、250 万像素上限。不可见或后台暂停；H5 点击暂停且分支伸展完成后停止动画帧。减少动态、低内存、省流量或 WebGL 不可用时保留静态连线与点击功能。
- **移除动态背景开关**：页面按钮、样式与配置中的四个暂停／恢复文案全部删除。配置版本升级到 11，编辑器可读取旧版 9/10 草稿，保留旧草稿原件并去掉废弃字段；下一次编辑才保存到新版 key。
- 不增加新依赖，不影响纯静态部署，按用户后续明确授权，验收后提交并推送 main（触发现有 GitHub Pages 工作流）。
