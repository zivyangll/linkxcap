## 1. 填写与交付规则

| 标记／字段 | 含义与填写方式 |
| --- | --- |
| O＝现官网可获取 | 本轮实际读取到的公开内容，可作为整理起点；公司确认是否继续使用 |
| F＝Figma可导出 | 可读取的文字、矢量或已有图片填充；不保证嵌入位图是高清原片，也不代表授权已确认 |
| C＝公司提供／确认 | 事实、译文、权利、公开范围、高清源文件、真实目的链接由公司批准 |
| D＝开发生成 | Web尺寸、格式转换、SVG路径实现、静态粒子图、分享图排版、图标导出等，可在源素材获批后制作 |

| P2 | 可选增强；未确认采用时，不纳入一期制作或采购 |

| 文案文件 | UTF-8 Markdown／可复制文档，禁止只交截图；提供最终中英文，标明对应编号 |
| 文件命名 | 如 `B01-logo-primary.svg`、`CO01-logo-color.svg`、`TM02-portrait.png`、`AR01.zh.md`、`AR01.en.md`；同一ID对应一个实体 |

| 授权与来源 | 说明商标、人物肖像、图片／插画、字体、音乐／视频的使用许可或所属方确认；授权文件可用内部受限链接交付，无须公开上站 |
