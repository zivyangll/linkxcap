# 星连资本 Link-X Capital 官网项目交接说明

交接基线：2026-09-19，`main` 分支，提交 `a3262a7`。

## 1. 项目目标

根据新版 Figma 设计稿，重构星连资本官网。

项目重点包括：

- 高质量还原 Figma 视觉稿。
- 实现滚动叙事、节点轨迹、渐变入场和 3D 拓扑交互。
- 支持中文和英文。
- 适配桌面端、平板及手机端。
- 保持较快的首屏加载和流畅的滚动性能。
- 最终生成纯静态 HTML、CSS、JavaScript，可部署到 GitHub Pages 或普通静态服务器。

## 3. 技术方案

项目使用：

- Astro 7：静态页面生成。
- TypeScript：交互逻辑。
- CSS、SVG：页面布局和基础视觉效果。
- GSAP、ScrollTrigger：滚动叙事和章节动画。
- Three.js：首页和投资组合的三维节点拓扑。
- Playwright：浏览器自动化测试和截图检查。
- GitHub Actions：自动构建并部署到 GitHub Pages。

部署后没有 Node.js 服务、数据库或服务端渲染依赖。

## 5. 已完成的功能

### 首页

首页由五个滚动章节组成：

1. 开场点沿竖线移动，文字逐渐出现。
2. 点进入圆弧轨迹，标题渐显并随滚动向左退出。
3. 关于我们内容横向进入，节点移动到指定位置。
4. 投资数字和内容分组入场。
5. 黑色 3D 节点拓扑，支持悬停、点击、发光和连接线反馈。

Three.js 模块采用延迟加载，滚动到附近后才下载和初始化。

### 投资组合

- 黑色背景拓扑图。
- 共展示 19 家投资组合公司。
- Logo 悬停时点亮并恢复品牌颜色。
- 点击公司进入对应详情页。
- 详情页右侧公司列表可以滚动。
- 右侧滚动时，左侧名称、Logo、分类、介绍和官网链接同步更新。
- 当前公司同步写入 URL，刷新后不会回到第一家公司。
- 支持方向键、Home、End 和触摸操作。

### 团队

- 当前只展示三人：张鸣晨、王璞、李文珏。
- 鼠标悬停左侧头像时，右侧出现对应人物介绍。
- 鼠标移开后介绍隐藏。
- 点击可以固定介绍，按 Escape 可以关闭。
- 移动端改为点击切换。

### Fellow／联系我们

- 使用 Figma Fellow 方案重新制作。
- 大标题描边转实心。
- 圆弧上的点左右摆动。
- 视频窗口随滚动放大。
- 页面底部包含 Join Us 和联系信息。
- 移动端使用自然滚动，避免长时间固定页面。

正式视频还没有提供，目前显示明确的“待提供”占位。

### 洞察

- 本轮没有大范围重构洞察页面。

## 6. 响应式及性能处理

页面至少覆盖：

- 360px 手机。
- 390px 主流手机。
- 768px 平板。
- 1440px 笔记本及桌面。
- 1920px 宽屏。

3D 场景具有以下保护：

- 进入可视区域附近才加载。
- 页面离开视口或浏览器进入后台后暂停。
- 桌面和手机使用不同的粒子数量、像素比和帧率。
- 支持 `prefers-reduced-motion`。
- Save Data、低性能设备、WebGL 失败时使用静态节点。
- 页面正文和链接不依赖 Three.js 加载完成。

2026-09-19 本地构建验证结果：

- CSS：17.3 KiB gzip。
- 全部 JavaScript（含按需编辑器）：约 191.6 KiB gzip；普通公开页面不请求编辑器代码或配置 JSON。
- Three.js 及拓扑模块按需加载，不进入每页首屏。

更细的普通 JavaScript 与可选三维模块拆分数据，见[会议评审修改与验收](07-会议评审修改与验收.md)。

## 8. 本地运行

环境要求：Node.js `>=22.12.0`。

```bash
cd <repo>
npm ci
npm run dev
```

默认开发地址带有 Astro `base`：

```text
http://127.0.0.1:4321/linkxcap/zh/index.html
```

生产构建：

```bash
npm run build
npm run preview -- --port 4321
```

运行全部浏览器测试：

```bash
npm test
```

上一轮记录为 58 项 Chromium 和 WebKit 测试全部通过；交接时已重新执行 `npm run build`，Astro 检查为 0 错误、0 警告，72 个页面构建成功。完整测试记录见第 12 节链接。

## 9. GitHub Pages 部署

向远端 `main` 分支推送后，GitHub Actions 自动执行：

1. 安装依赖。
2. 构建 Astro 静态页面。
3. 上传 `dist/`。
4. 发布到 GitHub Pages。

构建使用以下配置：

```text
SITE_URL=https://zivyangll.github.io
SITE_BASE=/linkxcap
PUBLIC_CONTENT_MODE=preview
```

目前处于预览内容模式，因此页面保留 `noindex`。正式发布前需要切换生产内容模式，并重新检查 canonical、sitemap 和搜索引擎配置。
