# 实现与维护说明

## 已落地的技术方案

| 项目       | 实现                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------- |
| 框架       | Astro 7.3.3，构建时输出 HTML；正文不依赖客户端渲染                                          |
| 类型与内容 | TypeScript；Astro Content Collections + Zod 验证文章元数据；公司 JSON、站点 TypeScript 数据 |
| 样式       | 原生 CSS 分层，统一品牌变量；1920px 对照稿，360px / 768px / 1440px / 1920px 自动测试        |
| 动效       | 首页加载完成后加载 GSAP 3.15.0 与 ScrollTrigger；文字揭示、轻量轨道视差；无滚动接管         |
| 粒子       | Canvas 2D 单场景；桌面 360、移动 95、弱设备／节流 50 个初始粒子；最多 30 fps；支持动态降档  |
| 暂停       | 可见区域检测、后台暂停、用户暂停、减少动态偏好；离开页面清理观察器和画布                    |
| 静态替代   | 轨道 SVG／WebP 与星域节点持续可见；Canvas 不可用时正文、节点和链接照常使用                  |
| 双语       | 两套静态 URL；切换语言保留公司／人物／文章位置和分类查询参数                                |
| SEO        | 静态标题、描述、lang、canonical、hreflang、OG、sitemap；mock 预览 noindex                   |
| 部署       | GitHub Actions 构建并上传 `dist/`，GitHub Pages 托管；无需运行服务或数据库                  |

| 范围                       | 处理                                                                                                    |

## 静态服务器与后续维护

| 场景         | 处理                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------- |
| GitHub Pages | Pages 使用 Actions；实体 `.html` 直达；自定义 `404.html`；不能配置任意响应头和服务端 301                              |
| 首页         | 根 `index.html` 进入 `/zh/index.html`，无 JavaScript 也能选择语言                                                     |
| URL 迁移     | 旧站已有 `.html` 路径沿用；自定义域名上线前核对所有历史链接，不在预览阶段改旧站 DNS                                   |
| 缓存         | 构建 CSS／JS 带 hash；原始 Figma 资源按内容 hash 命名。字体更新时建议升级文件名或做缓存刷新                           |
| 自建服务器   | HTML 短缓存；有 hash 的资源长缓存；启用 HTTPS、gzip/Brotli；404 指向构建产物                                          |
| 中国大陆访问 | 资源全部同域托管，不依赖 Google Fonts 等外部 CDN；GitHub Pages 的地区网络质量仍需上线实测，不能保证大陆运营商访问性能 |
| 表单         | 当前邮件和社交链接直达，没有后端表单；未来收集提交需另行选择外部服务                                                  |
| 内容发布     | 修改同一文章的中英文两份文件，保留 `translationKey` 和 `route`；构建失败先修复，勿绕过检查                            |
| 回滚         | 回退 `main` 到上一确认版本并重新运行 Pages 工作流                                                                     |

## 维护命令

```sh
npm ci
npm run build
npx playwright install chromium webkit
npm test
node scripts/performance-check.mjs
```

性能脚本需本地预览已在 4321 端口运行；输出在 `.cache/performance-report.json`。这是实验室检查，不是现场真实用户 INP 或全球可用性保证。

- 字体包含400、500、600、700、900五个衬线字重。修改文案后，运行 `scripts/collect-font-usage.mjs` 和 `scripts/subset-fonts.py`，再重新构建。
