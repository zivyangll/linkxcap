## 最新确认与验收方法

| 模块 | 当前实现 | 验收方法 |
| --- | --- | --- |
| PC 首屏进入 | 标题、正文、标识及轨迹自动渐显，约 1.15 秒；12px 模糊变清晰，不依赖滚动 | 刷新后不动鼠标滚轮，观察文字进入 |
| PC 首屏自动滚动 | 以右侧正文底部计算轨迹点的触发位置；触发后先停在第二屏“链接 AGI 时代的定义者”，不会直接跳到“关于我们” | 向下滚过首屏文字底部，检查第二屏停靠位置 |
| PC 后续章节 | 当前停靠点到下一停靠点的距离完成 75% 后自动过屏；第二屏之后是“关于我们”。阈值前维持原生滚动、不强制回弹；新滚动／按下鼠标可以打断过渡 | 先滚约 60% 应不跳屏，再滚过 75%；依次通过后续章节并向上返回 |
| 文字与点线 | 保留 PC 圆弧、点的连续轨迹和分批数据入场；关键标题从错开、模糊、松字距聚合到清晰状态 | 检查第二、三屏转场，以及研究数字出现的节奏 |
| 投资组合列表 | 恢复原来的静态网格、Logo 排版和 Hover 高亮。不保留本轮试做的旋转轨道、动态背景或暂停按钮 | 核对原网格与 Logo 悬停效果，点击进入对应公司 |
| 投资组合箭头 | 复用原稿箭头文件、圆框尺寸与样式，圆框中心跟随页面内鼠标；固定在卡片边缘的箭头在跟随状态下隐藏，避免重复 | 鼠标在卡片与页面留白移动；离开投资组合区域恢复系统光标 |
| 团队 | 校正三幅人物可见高度；点击显示介绍，不显示关闭按钮。点击介绍或按 Escape 收起，点击其他成员切换。边框与各自分割线保持相同内侧边距：PC 为 20 个设计像素，H5 为 18px | 分别打开三人，检查边距；三个卡片本身宽度不同，因此介绍框不再强制等宽 |
| Contact 首屏 | 加载后自动从描边／虚线变实心；延迟 0.1 秒、过渡 1.35 秒。中英文标题与副标题均适用，不需要滚动触发；滚动缩放时两层文字同步移动 | 停在顶部不滚动，观察实心状态自动完成；再向下检查正文不重叠 |
| H5 首页 | 保留独立的点线、圆弧、章节固定、文字与研究数据入场，PC 自动过屏逻辑不应用到 H5；短横屏使用自然滚动渐显 | 在 360／390／430／768px 检查正向、反向滚动、长英文正文、横竖屏切换 |
| 手机公司与洞察 | 公司选项、洞察分类使用黑／灰纯文字切换；关键 Logo 与名称高亮，操作使用点击。手机公司列表不保留桌面循环副本 | 横向滑动公司列表、切换公司、切换语言；点击洞察分类 |
| 视频 | 有片源时点击视频区域原位播放，无弹窗，保留原生控制条；离屏／后台暂停。PC 保留滚动放大，H5 保留自然比例 | 正式片源提供后检查声音、暂停、全屏与横竖屏 |
| 加载与视觉细节 | 图片预留尺寸，加载时轻量占位，失败时显示名称；PC Contact／页脚辅助字号缩小约 2–3px；处理装饰图片浅色边缘 | 限速或阻断图片请求，检查占位与失败回退；检查辅助文字和轨道边缘 |

PC 动画条件：至少 1024px、精细指针、支持 hover，且未开启“减少动态”。窄屏或触屏启用独立 H5 模块。两套动画在尺寸切换时分别卸载与重建；减少动态模式下恢复静态阅读。H5 不加载首页 Three.js，末屏节点以点击方式工作。

首屏阈值根据实际布局测量。例如当前 1440×900 中文页的五个停靠位置约为 `0 / 1580 / 3710 / 5134 / 6030`，首屏触发约 `213px`；这些是当前字体和视口的结果，不是写死的坐标。过屏使用加速后减速曲线，时长按距离限制在 0.5–1.6 秒。

这些时长与触发规则根据用户文字需求实现；已有 Figma 检查未获取到可执行的原型关键帧，不能称为 Figma 导出的原始动画。
