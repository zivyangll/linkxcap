# 14 · 全站字体大小清单

> **这是合并前的快照。** 字号已合并为 10 档、最小 12px，现行规范见 [15-字体规范](15-字体规范.md)。

> 采集日期：2026-10-08。方法：构建当前代码，用 Playwright 在浏览器里读取所有文字元素的 `getComputedStyle().fontSize`（中/英两种语言、10 类页面），首页额外做了逐屏滚动 + 点击星点采样。因此表中是**实际生效值**，不是 CSS 里的声明值。

## 怎么读这张表

- 视口标记：**桌** = 桌面 1920 宽（设计稿基准）；**平** = 平板 820 宽；**手** = 手机 390 宽。
- 桌面端（≥1024px）字号按视口宽度等比缩放：`实际字号 = 表中桌面值 × 视口宽度 / 1920`（>1920 时固定不再放大）。例如 1440 宽时 24px 实际是 18px。
- 手机端首页（H5）按 750 设计稿缩放：`实际字号 = 设计稿值 × 390 / 750`（即 ×0.52），所以会出现 10.4、56.14 这类小数。
- 小数用 `≈` 标出，已四舍五入到整数 px 归并。中英文字号不同时在位置里单独注明。
- 页面简称：首页 `/{lang}/index`、作品集 `portfolio`、公司详情 `portfolio/xxx`、团队 `team`、成员详情 `team-xxx`、洞察 `insights`、文章/资讯 `insights-xxx`/`news-xxx`、Fellowship `fellowship`、法律 `legal`、404。

## 需要关注的小字号

按采样结果，下面几处在常见视口下偏小，建议设计/产品确认：

1. **手机端首页** 多处正文只有 8–10px：焦点面板正文 ≈8.3px、关于/研究正文 ≈10.4px、星点/公司名标签 9px。成因是 H5 样式用 `calc(N × 750 稿)` 等比缩小（`home-h5.css`），Figma 750 稿中 16–20px 的字在 390 宽屏上被缩到 8–10px。
2. **桌面端低于 1920 宽时整体缩小**：作品集卡片行业标签设计值 8px，1440 宽时 6px、1200 宽时 5px；菜单底部法务设计值 10px，1200 宽时 6.25px。
3. 菜单按钮在 ≥1280px 时，只有完整顶栏（有横向导航的页面）会隐藏；公司详情页、首页星图屏等「精简顶栏」仍显示菜单按钮，所以桌面菜单的字号（24/30/20px 等）在这些页面可见。

## 局限

- 仅采样了首页、作品集、一个公司页（谦合益邦）、团队、一个成员页（张鸣晨）、洞察、一篇文章、一篇资讯、Fellowship、法律、404；其余 54 家公司页、其它成员页使用同一套模板，字号一致。
- 悬停态、折叠态（如团队成员简介）按 `display:none` 状态下的计算值读取；`::before`/`::after` 伪元素文字未单独统计。
- 触屏横屏大屏（如 iPad 横向 1024+）会命中 `hover: none` 规则，字号可能与「桌」列不同，未单独采样。
