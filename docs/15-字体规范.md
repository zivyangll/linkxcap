# 15 · 字体大小规范

> 2026-10-08。把 [14-字体大小清单](14-字体大小清单.md) 里的约 55 档字号合并为 **10 档**，最小 12px。

## 规范档位

| 档位 | 用途 | 典型位置 |
|---|---|---|
| **12px** | 最小字号：眉标、标签、元信息、版权 | `eyebrow`、文章作者/日期、星点标签、公司卡片行业标签、菜单底部法务 |
| **14px** | 辅助正文、按钮、小导语 | 「复制链接」、洞察摘要与「阅读全文」、文章目录、团队/洞察导语 |
| **16px** | 基础正文（`body` 默认） | 站点正文、顶栏导航、联系方式、公司/成员简介、文章/法律长文正文 |
| **20px** | 导语、一级正文、三级标题 | 文章摘要、首页焦点面板正文、洞察标题（手机）、法律/文章 `h3` |
| **24px** | 中号标题 | 卡片/成员姓名、副标题、Fellowship 眉标、菜单顶栏 |
| **32px** | 二级标题 | 文章/法律 `h2`、菜单主导航、洞察标题、小屏页标题 |
| **44px** | 小屏大标题 | 手机/平板页标题、首页手机端标题、文章 `h1`（小屏） |
| **60px** | 桌面页标题 | 作品集/团队/洞察/公司页页标题、文章 `h1`（桌）、成员 `h1`、平板首页大标题 |
| **81.333px** | 首页展示大字 | 首页 hero、关于、`10,000+`、`我们关注什么`；公司详情名称 |
| **112px** | 最大展示字 | Fellowship 主标题、首页开场英文标题、404 |

## 归档规则

按「视口 + 写法」分三种，数值都取自上表：

| 场景 | 写法 | 例 |
|---|---|---|
| 桌面（≥1024px） | `max(12px, calc(N * var(--u)))`，N 为 1920 宽下的字号；>1920 宽固定不放大 | `max(12px, calc(24 * var(--u)))` |
| 平板/手机（≤1023px） | 固定 px，或首尾落在档位上的 `clamp` | `16px`、`clamp(32px, 8.205vw, 44px)` |
| 首页手机 H5 | `calc(N * var(--k))`，N 为 390 宽下的字号，随屏宽放大（`--k` 定义在 `home-h5.css`，取代原 750 稿 `--m` 的字号用法） | `calc(44 * var(--k))` |

原值归入最近的档位：

| 原值（px） | → 档位 |
|---|---|
| ≤12.9 | 12 |
| 13–14.9 | 14 |
| 15–18.4 | 16 |
| 18.5–21.9 | 20 |
| 22–27.9 | 24 |
| 28–37.9 | 32 |
| 38–51.9（手机 38–56.9） | 44 |
| 52–70.9（手机 57–74.9） | 60 |
| 71–95.9 | 81.333 |
| ≥96 | 112 |

**最小 12px**：原来的 8、9、10、11px 全部提到 12px；桌面等比缩放的字号都带 `max(12px, …)` 下限，1200/1440 宽也不会小于 12px；首页 H5 在窄屏（如 360 宽）同样带 12px 下限。

## 首页节点标签

开场屏的 `Chapter 01`（`.chapter`）和第二屏的 `循星而行 / 远星初亮`（`.orbit-label`）是同一类「节点标签」，共用一套样式，中英文一致：

| 项 | 值 |
|---|---|
| 字体 | 无衬线（`--sans`），常规字重，**不斜体**（原 `循星而行` / `Follow the stars` 为斜体衬线） |
| 字号 | 桌面 16px（1920 宽，随宽度缩放，下限 12）；手机 14px |
| 颜色 / 透明度 | `#423f5e`，不透明（原 `Chapter 01` 为黑色 40% 透明） |
| 字距 | 0 |

英文轨道标签在无衬线下更宽，所以桌面端整体左移 26 个设计像素，节点菱形的位置不变，文字末端离菱形约 10px。

## 例外与说明

- 相对单位（`inherit`、`em`）不属于档位：`font-size: 1em` / `0.75em` 跟随父级，父级落在档位上，子级也随之确定。
- 平板（820）与小屏（360）下，首页 H5 和 `clamp` 流体字号会在两个档位之间平滑变化；规范约束的是 390（手机）和 1920（桌面）两个基准宽度，以及「任何宽度不小于 12px」。
- 内容编辑器后台页（`src/pages/a4f9c2e71b6d4830c5a8e2f94d7b136c.astro`）不是对外页面，未纳入规范。
- 新增字号时只能用上表档位；需要新档位先改本文档。
