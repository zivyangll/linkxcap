### 文章 1：在 AGI 到来之前，我们先做什么？ / What Should We Build Before AGI Arrives?

**日期 / Date**：2026\-01\-04。**分类 / Category**：基础模型与学习范式 / Foundation Models \& Learning。**列表摘要 / Card summary**：从模型能力、智能体和真实场景出发，讨论技术尚未收敛时的创业重点。 / A view of model progress, agents and the practical work ahead while the path to AGI remains open\.

**中文正文**

#### 继续探索模型能力的边界

模型的规模、训练数据和计算效率仍在影响智能能力的上限。推理、多模态和新训练方法不断发展，但技术路线尚未定型。对研究团队而言，重要的是找到能够带来可验证能力提升的问题，并持续迭代。

#### 让已有能力进入真实任务

模型在评测中的表现与完成真实工作之间仍有距离。智能体需要在复杂环境中理解目标、调用工具、处理反馈，也需要在不同任务之间迁移。更好的训练环境、评价方法和真实使用数据，是释放模型能力的关键。

#### 为用户创造价值

应用团队应从具体工作出发，把模型能力变成可靠、可用的产品。医疗、科研、制造和物理世界等领域各有不同约束；能否理解场景、形成反馈循环并随着模型进步快速调整，决定产品的长期价值。

**English body**

#### Keep advancing model capability
