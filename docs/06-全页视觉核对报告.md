# 全页 Figma 视觉核对报告

**结论：已完成 `final` 全部 28 个画板／状态的读取和核对，并修正一轮实现；当前仍未达到“一个像素都不能差”的验收标准。** 19 组可对应截图均有非零差异，其余 9 个画板属于未实现状态或备选方案，未计为通过。

完整证据：[交互对照页](verification/visual-audit/index.html) · [原始指标](verification/visual-audit/after-metrics.json) · [70 页／280 次检查](verification/visual-audit/route-audit.json) · [动效读取记录](verification/visual-audit/motion-inventory.json)。

## 1. 读取范围与测量条件

- 设计来源：[Figma final](https://www.figma.com/design/CTEAWCezlfopOXN5WcsqMa/Link-X--Copy-?node-id=2002-2)。28 个画板均读取设计上下文、原生尺寸截图和递归动效数据。
- 逐个画板的动效工具均返回 `nodes: []`；全页原型扫描覆盖 2102 个节点，没有读取到 `reactions`。这只能证明本次工具可读取范围内没有关键帧／连线，不能推断设计师没有动效意图。现有 GSAP／粒子时序属于实现方案。
- 截图：Chromium，1920 CSS px 宽，DPR 1；1080／1081px 单屏按原稿设置，长页自然截全页；等待字体和可见图片解码。减少动态偏好用于稳定状态，粒子停止。
- 原图与网页均按原生像素比较，不缩放、不自动位移对齐、不遮罩正文或功能控件。并排预览可缩放，但指标始终取原始分辨率。
- 修改前基于 `4ef1aa4`；早期1081px画板的网页截图高度为1080px，比较时补齐缺失区域且计入差异。修改后19组画布尺寸全部与对应原稿一致。
- 网页导航高亮按当前栏目，Figma 多数画板固定高亮 Philosophy；网站保留双语切换、MOCK提示及可访问性操作，这些差异没有从指标中删除。
- 浏览器和Figma的字体版本、字形栅格化、亚像素抗锯齿可能不同。因此本轮没有把“看起来相近”或低差异百分比表述成100%还原。

## 7. 验证结果与复现

- `npm run build`：72个HTML、70个内容页，本地链接、SEO、资源存在性与CSS／JS预算通过。
- Chromium＋WebKit：38项测试通过，包括新增星域企业链接和英文手机长标题测试。
- 70个实际内容URL×360／768／1440／1920px：280项检查，0个页面级横向溢出、破图、脚本错误或非200。该检查不等同于像素一致。
- 限速实验室检查：中文首页LCP中位数0.596s、英文首页0.568s、中文投资组合1.468s；三者CLS为0。CPU4倍、1.6Mbps、150ms、本地Chromium；不是线上RUM或全球网络结果。
- 每个Figma节点的原图在`verification/visual-audit/reference/`，修正前／后在`before/`与`after/`，红色差异图在`diff/`。

```sh
npm run build
npm run preview -- --port 4321
node scripts/capture-figma-audit.mjs after
node scripts/compare-figma-audit.mjs after
node scripts/audit-routes.mjs
node scripts/build-audit-gallery.mjs

```
